Molecular Docking Tutorial : A Complete Beginner's Guide to Computational Drug Discovery

Molecular docking is one of the most widely used techniques in computational drug discovery, predicting how small molecules bind to protein targets to guide drug design. This molecular docking tutorial provides a complete, step-by-step guide for beginners, covering everything from obtaining protein structures to interpreting docking results. This molecular docking tutorial uses freely available tools so that anyone can follow along regardless of their computational resources.


Whether you are a biologist wanting to understand computational methods, a chemist exploring drug design, or a student learning bioinformatics, this molecular docking tutorial will give you the practical skills to run your own docking experiments. By the end of this molecular docking tutorial, you will be able to set up, run, and interpret molecular docking calculations for any protein-ligand system.

Molecular Docking Overview

Molecular docking predicts the preferred binding orientation and estimated binding affinity of a small molecule (ligand) within the binding site of a protein (receptor). This molecular docking tutorial focuses on AutoDock Vina, one of the most widely used and cited free docking programs. Molecular docking uses a scoring function to evaluate binding poses and ranks them by estimated binding energy, with more negative values indicating stronger predicted binding.

  • Binding pose prediction for drug-protein complexes
  • Scoring function evaluation of binding energy
  • Ranking of poses by predicted binding affinity
  • Virtual screening of compound libraries against targets

Structure Preparation in This Molecular Docking Tutorial

This molecular docking tutorial covers structure preparation as the most critical step. For the protein: download the structure from the RCSB Protein Data Bank, remove water molecules and non-essential ligands, add hydrogen atoms, and assign Gasteiger charges using AutoDockTools. For the ligand: draw or download the structure, generate a 3D conformation using Open Babel, and add hydrogen atoms and partial charges. Poor structure preparation is the most common cause of poor docking results.

  • Download protein structure from RCSB PDB
  • Remove waters and add hydrogens to protein
  • Generate ligand 3D structure with Open Babel
  • Assign partial charges to both protein and ligand

Running the Docking Calculation

In this molecular docking tutorial, the docking calculation is set up by defining a grid box around the binding site using AutoDockTools or a text editor. The grid box center and dimensions must encompass the entire binding site with some margin. Run AutoDock Vina from the command line with the prepared protein and ligand files and the grid box parameters. Vina will output the top-ranked binding poses with their estimated binding affinities.

  • Define grid box around the protein binding site
  • Set grid box center and dimensions in config file
  • Run AutoDock Vina from the command line
  • Collect output poses and binding affinity scores

Interpreting Results in This Molecular Docking Tutorial

This molecular docking tutorial explains result interpretation: examine the top-ranked pose in PyMOL or UCSF Chimera; identify hydrogen bonds, hydrophobic contacts, and pi-stacking interactions with key binding site residues; compare the docked pose with any known co-crystal structure if available; use PLIP (Protein-Ligand Interaction Profiler) for automated interaction analysis. Validate your docking setup by re-docking a known co-crystal ligand and checking RMSD against the experimental pose.

  • Visualize top-ranked pose in PyMOL or UCSF Chimera
  • Identify key binding interactions with active site residues
  • Use PLIP for automated interaction profiling
  • Validate by re-docking known co-crystal ligands
